## ✨ Visual Hierarchy

```
1️⃣ Welcome back, User 👋
   └─ Largest heading (22px)
   └─ Personal, friendly tone

2️⃣ Your Voice Matters
   └─ Secondary heading (16px)
   └─ Blue accent color
   └─ Builds trust

3️⃣ Description text
   └─ Body text (15px)
   └─ Reassures user
   └─ Builds confidence

4️⃣ Statistics Cards
   └─ Large numbers (36px)
   └─ Visual focal points
   └─ Color-coded for quick scanning

5️⃣ Card labels
   └─ Supporting text (14px)
   └─ Explains what numbers mean
```

## 🎯 User Experience Flow

```
User opens dashboard
        ↓
Sees friendly welcome message
        ↓
Reads trust/confidence message
   ├─ "This is secure"
   ├─ "Process is transparent"
   └─ "We care about your concerns"
        ↓
Sees three key statistics
        ↓
Can quickly gauge system status
        ↓
Blue card → Overall complaint volume
Orange card → Attention needed (pending)
Green card → Positive outcome (resolved)
        ↓
User feels informed & confident
```
