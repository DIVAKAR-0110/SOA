## 🎬 User Interaction Flow

```
USER JOURNEY

1. LANDING ON DASHBOARD
   ↓
   ✓ Sidebar loads (280px fixed on desktop)
   ✓ "Lodge Complaint" is default active
   ✓ All menu items visible
   ↓

2. HOVER OVER MENU ITEM
   ↓
   ✓ Item slides right (4px)
   ✓ Color changes to blue (#004a99)
   ✓ Background becomes light gray
   ✓ Icon scales up (1.15x)
   ✓ All smooth (0.3s animation)
   ↓

3. CLICK MENU ITEM
   ↓
   ✓ Item becomes active
   ✓ Left accent bar appears
   ✓ Color stays blue
   ✓ Navigation occurs
   ✓ Content updates
   ↓

4. CLICK DELETE ACCOUNT
   ↓
   ✓ Confirmation dialog shows
   ✓ "Are you sure?" message
   ✓ Can cancel or confirm
   ✓ If confirmed, navigates
   ↓

5. MOBILE: TAP HAMBURGER
   ↓
   ✓ Sidebar slides from left
   ✓ Overlay appears (dark bg)
   ✓ 0.3s smooth animation
   ✓ Menu items become clickable
   ↓

6. MOBILE: TAP OVERLAY
   ↓
   ✓ Sidebar closes (0.3s)
   ✓ Overlay disappears
   ✓ Main content visible again
```
